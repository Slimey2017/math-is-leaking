# AI Learning Project

This project is an AI learning application built using only HTML and JavaScript. It implements a simple learning algorithm that can be trained with data and make predictions based on learned patterns.

## Project Structure

```
ai-learning-project
├── src
│   ├── index.html          # Main HTML document
│   ├── css
│   │   └── styles.css      # Styles for the application
│   ├── js
│   │   ├── main.js         # Main JavaScript file
│   │   ├── ai.js           # AI learning algorithm
│   │   ├── neuralNetwork.js # Neural network implementation
│   │   └── utils.js        # Utility functions
│   └── data
│       └── trainingData.json # Training data for the AI
├── README.md               # Project documentation
└── .gitignore              # Files to ignore in version control
```

## Setup Instructions

1. Clone the repository to your local machine.
2. Open the `index.html` file in a web browser to run the application.

## Usage Guidelines

- The AI can be trained using the data provided in `src/data/trainingData.json`.
- Modify the training data as needed to experiment with different learning scenarios.
- The application is designed to be simple and educational, demonstrating the basics of AI and neural networks without the use of external libraries or APIs.
